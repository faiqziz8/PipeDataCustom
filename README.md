# Pipe Data Pro+

Aplikasi data & kalkulator piping (pipa baja ASME B36.10M/19M, flange B16.5/B16.47/B16.36, fitting B16.9/B16.11/MSS SP-97, valve, gasket B16.20/B16.21, line blank B16.48, pipa & fitting PE, tebal dinding B31.8/B31.3, pipe span, HDD, konversi gas MMBTUD↔MMSCFD, dll.).

## Pasang di GitHub Pages
1. Buat repository baru, mis. `PipeData`.
2. Upload SEMUA isi folder ini (index.html, manifest.webmanifest, sw.js, folder icons) — bukan file zip-nya.
3. Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
4. Buka `https://<username>.github.io/PipeData/` di Safari iPhone → Share → **Add to Home Screen**.

## Update
Ganti `index.html` dengan versi baru, lalu naikkan `VERSION` di `sw.js` (mis. `pipedata-v2`) supaya cache offline ikut diperbarui.

Catatan: data standar sebagian diisi dari referensi/ingatan — verifikasi dengan standar & katalog vendor sebelum dipakai untuk dokumen resmi.
